# external_search_gui

## 概要
- [external_search](https://github.com/gkjg8787/external_search)を使用してカスタム検索を行うWEBアプリ

## 起動方法
- このリポジトリをコピーしたディレクトリ内での実行を前提とする。

- dockerを起動する前にcreate_config.shを実行して必要な設定ファイルを作ります。
  `bash create_config.sh`

- 作成された`search`ディレクトリ下に`GEMINI_API_KEY=xxx`が書かれた.envファイルを作成してください。
> [!NOTE]
> `GEMINI_API_KEY`は自身で取得する必要があります。

- コンテナを起動します。
 `docker compose up -d`

- URLにアクセス
 `localhost:8110/search/`



## 操作方法
- 検索用ラベルを作成するとラベルで検索画面でチェックボックスをONにしたカスタム検索が行えるようになります。

### ラベルの種類
- ラベルには以下の2種類あります。検索ラベルは検索用の設定があり、商品ページラベルでは一致するURLパターンの設定が必要です。
  - ラベル（検索ラベル）
  - 商品ページラベル（ウォッチ登録用ラベル）

### 検索ラベルの作成
- ラベル一覧からラベルを作成できます。手動または自動で作成できます。

#### 自動作成
- 「ラベル一覧」画面の「自動作成」ボタンからラベル作成ページに移動します。
- 以下の項目を入力して、自動で作成します。
    - **URL**: 対象のECサイト。
    - **検索ワード**:自動でダウンロード設定を作成する場合、必要です。対象サイトで商品がひっかかる検索ワードである必要があります。入力シない場合はダウンロード設定は固定の値になります。
- 実行すると対象サイトへアクセスし解析できればラベルが作成されます。カテゴリが抽出できた場合は{URL}_{カテゴリ}のフォーマットでカテゴリ毎のラベルが作成されます。実行だけではラベルは登録されません。
- 実行結果を確認後、登録するボタンを押すとラベルが登録されます。

> [!IMPORTANT]
> ラベルの自動作成のサイト解析方法はルールベースなので対応できないサイトでは使用できません。


#### 手動作成
- 「ラベル一覧」画面の「新規追加」ボタンからラベル作成ページに移動します。
- 以下の項目を入力して、検索ラベル設定を作成します。
    - **ラベル名**: 検索を識別するための名前です。
    - **ベースURL**: 検索対象サイトのURLの基本部分です。（例: `https://www.suruga-ya.jp/search`）
    - **クエリ**: 検索キーワードを指定するURLパラメータです。（例: `search_word`、※検索URLが`https://www.suruga-ya.jp/search?search_word=xxx`の場合）
    - **クエリエンコーディング**: 検索キーワードをエンコードする際の文字コードです。（例: `utf-8`）
    - **ダウンロードタイプ**: ページの取得方法を選択します (`httpx`, `selenium`, `nodriver`)。
    - **ダウンロード設定**: `external_search`ライブラリで使用する詳細なパーサー設定をJSON形式で記述します。
- 入力後、「確認画面へ」ボタンを押すと、入力内容の確認とプレビューができます。
- **プレビュー機能**:
    - 「学習URL」に実際に存在する商品ページなどのURLを入力し、「プレビュー」ボタンを押すと、現在の「ダウンロード設定」で正しく情報（価格、タイトルなど）が抽出できるかテストできます。
    - 期待通りにデータが取れるまで「ダウンロード設定」のJSONを修正し、再プレビューを繰り返します。
      > [!NOTE]
      > 一度データを取得した場合、パーサ（データの変換プログラム）が自動的に作られますが、再度パーサを作成する（変える）には **ダウンロード設定** の中に`"recreate_parser":true`を含める必要があります。
- 設定が完了したら、「登録」ボタンを押してラベルを保存します。

### ラベルの編集/削除
- 登録したラベルはラベル一覧から編集/削除することが可能です。

### ラベルで検索
- 登録したラベルの設定でキーワード検索ができます。

### 商品ページラベルの作成
- 商品ページラベル一覧からラベルを作成できます。
- 「商品ページラベル一覧」画面の「新規追加」ボタンからラベル作成ページに移動します。
- 以下の項目を入力して、商品ページラベルを作成します。
    - **ラベル名**: 設定を識別するための名前です。
    - **URLパターン**: 対象サイトのURLの基本部分でパターンタイプで設定した一致方法に左右されます。（prefixの場合の例: `https://www.suruga-ya.jp/product/detail/`）
    - **パターンタイプ**: URLに一致するパターン方法です。prefixの場合は前方一致。regexの場合は正規表現で一致します。（例: `prefix`, `regex`）
    - **ダウンロードタイプ**: ページの取得方法を選択します (`httpx`, `selenium`, `nodriver`)。
    - **ダウンロード設定**: `external_search`ライブラリで使用する詳細なパーサー設定をJSON形式で記述します。
- 入力後、「確認画面へ」ボタンを押すと、入力内容の確認とプレビューができます。
- **プレビュー機能**: 
    - 「学習URL」に実際に存在する商品ページなどのURLを入力し、「プレビュー」ボタンを押すと、現在の「ダウンロード設定」で正しく情報（価格、タイトルなど）が抽出できるかテストできます。
    - 期待通りにデータが取れるまで「ダウンロード設定」のJSONを修正し、再プレビューを繰り返します。
      > [!NOTE] 
      > 一度データを取得した場合、パーサ（データの変換プログラム）が自動的に作られますが、再度パーサを作成する（変える）には **ダウンロード設定** の中に`"recreate_parser":true`を含める必要があります。
- 設定が完了したら、「登録」ボタンを押してラベルを保存します。

### グループの作成
- グループを作成することで検索ラベルをグループとしてまとめることができます。作成したグループは`ラベルで検索`でグループ一覧として使えます。
- 「グループ一覧」画面の「新規グループ追加」ボタンからグループ作成ページに移動します。
- グループ名を入力して作成します。
- 作成したグループに作成済みの検索ラベルを追加/削除できます。
